# CSC103 Final Project - Antony J & Marcos O

Welcome to **"Alone? On Planet 4546b"**.

This is a text-based survival adventure game created in C++ for the CSC103 Final Project.

## Story

You play as Carl, a lonely 35-year-old man living in the year 2126. After a catastrophic emergency aboard a space cruise ship, Carl is accidentally launched away inside an escape pod and crashes onto Planet 4546b.

Now you are stranded on an unfamiliar alien world filled with abandoned facilities, infected creatures, and mysterious research experiments. You must explore the planet, gather resources, manage survival stats, and repair a rocket in order to escape.

## Features

- Multiple explorable locations
- Survival system (health, hunger, thirst, stress)
- Inventory system
- Random number mini-game
- Combat choices
- Multiple story/lore discoveries
- ASCII art
- Rocket escape ending

## Programming Concepts Used

- Classes / Structs
- Functions
- Loops
- Conditional Statements
- Vectors
- Randomization using `rand()`
- Global variables
- User input validation
- Ways to print ASCII art

## Contains:

- 31 functions
- 2 structs/ classes (Player, Enemy)
- 3 objects (Carl, bear, zombie)
- 1 rand() game (Keypad guessing game)
- 7+ changing variables (health, hunger, thirst, stress, bullets, fuel, battery, launchCode, inventory)
- Consistent outputs for stats
- 35+ decision/ branch points
